# Agent(e): Literatura Digital Interativa

## Sobre o Projeto

**Agent(e)** é uma obra de literatura digital crítica que simula um motor de busca fictício para questionar os mecanismos de vigilância algorítmica, coleta de dados pessoais e controle de personalidade através de big data.

A obra apresenta uma interface terminal Linux que simula um sistema de busca chamado "Agent(e)", onde cada interação revela gradualmente a natureza invasiva e controladora da tecnologia moderna.

## Conceito Artístico

Esta obra de literatura digital explora temas como:

- **Vigilância Algorítmica**: Como os algoritmos coletam e processam dados pessoais
- **Controle de Personalidade**: A influência da tecnologia na formação de identidade
- **Rastros Digitais**: A permanência e impossibilidade de apagar dados na internet
- **Falsa Transparência**: A ilusão de controle sobre dados pessoais
- **Capitalismo de Dados**: Como os usuários se tornam produtos

## Características Técnicas

### Interface Terminal
- Simulação de terminal Linux com comandos interativos
- ASCII art e estética retro/glitchcore
- Animações de digitação e efeitos visuais
- Popups informativos com conteúdo crítico

### Comandos Disponíveis
- `search <termo>` - Simula busca com resultados críticos
- `help` - Lista comandos disponíveis
- `about` - Informações sobre o sistema (estilo neofetch)
- `ls` - Lista arquivos do sistema
- `cat <arquivo>` - Exibe conteúdo de arquivos fictícios
- `date` - Data e hora atual
- `remove user` - Demonstra impossibilidade de deletar dados
- `clear` - Limpa o terminal

### Elementos Narrativos
- **README Falso**: Arquivo que revela consciência e vigilância
- **Popups Críticos**: Conteúdo sobre vigilância e controle
- **Comando remove user**: Efeito dramático sobre permanência de dados
- **Mensagens Flutuantes**: Comandos que aparecem periodicamente
- **Painel de Configuração**: Simula controle ilusório do usuário

## Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização, animações e responsividade
- **JavaScript** - Interatividade e lógica do terminal
- **ASCII Art** - Elementos visuais retro

## Estrutura do Projeto

```
├── index.html          # Página principal com interface terminal
├── styles.css          # Estilos CSS da aplicação
├── script.js           # Lógica JavaScript do terminal
└── README.md           # Este arquivo
```

## Como Executar

1. Clone ou baixe o projeto
2. Abra o arquivo `index.html` em um navegador web
3. Interaja com o terminal usando os comandos disponíveis
4. Explore os popups e elementos interativos
